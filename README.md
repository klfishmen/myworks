## 📖 專案簡介 (Overview)

「基隆鮮物．崁仔頂小商人 (khàm-tíng)」是一套為台灣知名夜間傳統漁市——**基隆崁仔頂** 量身打造的團購電商與營運管理系統。

本專案運用 **Vibe Coding（AI 提示詞工程）** 理念，深入解決傳統海鮮市場面臨的真實痛點：
1. **凌晨靠港限量現流漁獲**：瞬息萬變的庫存需在每日 12:00 準時開賣，必須具備動態防超賣與搶購視覺反饋。
2. **生鮮低溫冷鏈物流**：針對超商冷凍櫃常滿載退件問題，首創 **7-11 與全家雙超商門市強制備選填寫機制**。
3. **單張獨立對帳 ✕ 當週併單出貨**：買家可多次下單並各別回報帳號末五碼，後台系統自動依買家手機與暱稱歸戶，合併計算階梯免運門檻並一鍵列印出貨單。
4. **零伺服負擔架構**：前端採用純 HTML5 / Tailwind CSS / Vanilla JS 單一檔案 SPA 架構，後端深度串接 Google Apps Script (GAS) WebApp API 與 Google 試算表，實現零維運成本的自動化雲端資料庫。

## 🚀 系統核心功能與架構特色

### 🛒 買家搶購前台 (`index.html` in 1105乙)
* **🔥 每日 12:00 現流定時搶購**：開賣前倒數計時鎖定，到點即時解鎖；內建測試解鎖工具開關。
* **⚡ 庫存 300% 脈衝動畫 (`stockBump`)**：現流漁獲搶購時數量即時扣除，並觸發強烈光暈動畫營造緊張感。
* **🚚 滿額階梯免運進度條**：
  * 合併小計 $\ge$ $3,000：**免低溫運費 ($0)**
  * 合併小計 $\ge$ $2,000 且 $<$ $3,000：**運費 $60**
  * 合併小計 $<$ $2,000：**運費 $130**
* **🔒 防重複送出鎖定機制**：點擊「送出訂單」後按鈕即時 disabled 並顯示 `⏳ 正在建立訂單...`，防止心急重複扣款。
* **💬 雙軌留言板**：區分公開社群討論區與以「手機末 4 碼」識別的私人改單私訊區。

### ⚙️ 管理者控制台 (`main.html` in 1105乙)
* **📋 訂單紀錄與對帳審核**：即時從 Google 試算表載入訂單，支援手動收款核銷。
* **📦 當週併單出貨單彙整**：自動彙整同一客戶當週所有已核銷訂單，支援一鍵列印不重複出貨單（`isPrinted` 狀態鎖定）。
* **🐟 商品庫存與圖文管理**：支援現流與冷凍商品照片網址、規格、單價、口感煮法說明欄之即時增修與上下架。
* **👥 VIP 客戶資料庫**：自動統計客戶消費次數、總金額與偏好門市。
* **💬 對話紀錄備份**：集中備份買家私訊與改單備註。

## 🛠️ 技術棧 (Tech Stack)

- **前端核心**：HTML5, CSS3, JavaScript (ES6+ Vanilla JS)
- **樣式與佈局**：Tailwind CSS (CDN & Inline CSS), CSS Grid, Flexbox, Glassmorphism
- **字型與圖標**：Google Fonts (`Noto Sans TC`, `Plus Jakarta Sans`)
- **雲端資料庫**：Google Apps Script (GAS) WebApp API (RESTful endpoint, LockService 併發鎖定, MailApp 自動信件派發)
- **資料儲存**：Google Sheets (試算表雲端資料庫)、HTML5 Web Storage (LocalStorage)
- **報表匯出**：UTF-8 with BOM CSV Export, Window.print() 列印樣式適配
- **代碼架構**：Single-file Single Page Application (SPA)，無伺服器、零外部 npm 構建依賴

## 💻 快速開始 (Quick Start)

本專案為純靜態架構，無須繁瑣的 Node.js 構建步驟：
1. **直接開啟**：在本地端以任何瀏覽器雙擊開啟 [`index.html`](index.html) 即可體驗完整作品集。
2. **VS Code Live Server**：使用 VS Code 的 Live Server 擴充套件於本地 `http://127.0.0.1:5500` 開啟。
3. **GitHub Pages 部署**：推送至 GitHub 後，於儲存庫的 `Settings -> Pages` 選擇 `main` 分支根目錄即可自動發布為線上網站！
