# ⚓ 基隆鮮物．崁仔頂小商人 (khàm-tíng) ｜ 完整網站建構指南、結構、功能與操作手冊

本文件為「基隆鮮物．崁仔頂小商人」電子商務與後台管理系統之最終完整規格標準。本版本已全面移除現場實況影音區，專注於極速現流搶購、常態冷凍嚴選、雙軌購物車統整結帳、自動化信件對帳以及 6 大後台營運管理模組。

## 一、 網站系統架構與專案結構

本系統採用現代化前端單頁應用架構（SPA），結合 Google Apps Script 與 Google 試算表作為雲端後端資料庫，實現零成本、高效能的團購電商與對帳系統。

### 1. 專案檔案結構
```text
my-seafood-groupbuy/
├── index.html           # 🛒 買家前台主頁（純淨點購、現流搶購、購物車極速結帳）
├── main.html            # 👑 內部管理者系統（含沙盒切換與 6 大後台管理分頁）
└── Code.gs              # ☁️ Google Apps Script 後端（處理 API 寫入、試算表同步與信件通知）
```

## 二、 核心功能規格說明

### 1. 買家前台功能 (`index.html`)
* **進站免登入快速搶購**：訪客無需繁瑣註冊，即可即時瀏覽每日現流野生海鮮與常態冷凍嚴選商品。
* **每日現流 3 倍放大動態與防超賣機制**：
  * 現流漁獲具備獨立庫存，點擊「立即搶購」時即時扣減，並觸發強烈的 `0.8s` 數字放大與發光脈衝特效 (`stockBump3X`)，營造深夜魚市搶購氛圍。
* **智慧購物車與運費自動計算**：
  * 支援現流與冷凍商品自由混搭
