## 一、 本地端開發與上線部署測試流程 (VS Code + Firebase)

1. **開發與測試步驟**：
   * **第一步：本地端測試**：開發人員使用 **VS Code** 進行本地端環境建置與程式碼預覽測試。確認所有前端互動、沙盒開關與 UI 正常運作後，始可實裝上線。
   * **第二步：雲端服務對接**：完整串接 Firebase Google Authentication 與 Cloud Firestore 雲端資料庫。
   * **第三步：安全與防超賣機制**：部署 Firestore Security Rules，並透過 Cloud Firestore `runTransaction` (原子交易) 機制進行庫存扣減，防止超賣。
   * **第四步：權限驗證**：嚴格限制僅指定管理員信箱 (`twvisa2009@gmail.com`) 能夠解鎖並進入「👑 營運後台」進行核銷與管理。

## 三、 現流商品提前預告、動態庫存與高亮凸顯機制

1. **現流商品提前上架預告與 12:00 準時解鎖**：
   * 管理員可提前將現流商品上架至網頁上進行「預告展示」，讓訪客提早瀏覽產地規格、重量與實拍影音。
   * 在到達每日中午 12:00 之前，現流商品會顯示**倒數計時**且**禁止下單**（加入購物車按鈕為鎖定狀態）；到達 12:00:00 後自動定時解鎖開放搶購。
2. **現流商品剩餘數量放大與動態特效**：
   * 現流商品的「剩餘數量」字體級數必須**顯著放大（特大字體，如 `text-3xl` 或 `text-4xl`，搭配粗體與琥珀金 `#f59e0b` 或警示色彩）**。
   * 當其他使用者下單或自己加入購物車扣減庫存時，系統透過即時監聽（Firestore Realtime Listener）自動更新最新數量，並加上**簡單的動態更新凸顯效果**（例如脈衝動畫 `animate-pulse`、閃爍或短暫淡入淡出高亮背景），營造熱烈搶購的臨場感。
3. **數量下拉與防超賣**：
   * 現流商品提供 `1 ~ 10` 份數量下拉選單（或快選按鈕），動態綁定剩餘庫存上限（`max="${remaining}"`），超過庫存自動擋下並跳出溫馨提示。

## 七、 訂單與物流機制（每週出貨週期 + 單張獨立對帳 + 當週併單）

1. **每週出貨週期定義**：
   * 規定為「每週二中午 12:00 起算至當週週日中午 12:00 為一個完整出貨週期」，並於網站公告與信件中明確告知顧客。
2. **單張獨立對帳與資安零暴露**：
   * 顧客每次下單均成立獨立訂單，便於填寫匯款後 5 碼、收件人與指定超商門市。
   * **網頁公開區域絕對零暴露銀行帳號**（一個字都不出現），完整匯款帳號（**中國信託 822：`200532784005`**）僅在結算成功彈窗與 Email 中顯示。
   * 每一張訂單需經管理員確認入帳後，狀態切換為「已對帳核銷 (`status = verified`)」。
3. **同買家多單併單出貨與運費計算**：
   * 系統自動依【Google 帳號 UID】歸戶同一位買家的所有當週已核銷訂單。
   * 合併運費級距規則：
     * 合併小計 $\ge$ \$3,000：免運費 ($0)
     * 合併小計 $\ge$ \$2,000 且 $<$ \$3,000：運費 $60
     * 合併小計 $<$ \$2,000：運費 $130
   * 當該買家當週所有訂單全數完成核銷後，解鎖【列印多單彙整出貨單】按鈕（包含明細、數量、收件人、手機、雙超商門市：7-11 與全家各一）。

## 十、 常見問題 QA 專區（完整問答集）

1. **Q1：請問需要登入才能買魚嗎？為什麼要用 Google 登入？**
   * A：是的，為了保護您的購物安全、自動核對您的當週訂單與點數累計，本站採用 **Google 帳號快速登入**。登入後系統才能正確記錄您的專屬身分（UID），並在您下單時自動帶入您的 Email，方便接收訂單確認信與出貨通知喔！
2. **Q2：每日現流海鮮是什麼時候開賣？為什麼有時候會顯示「已售完」？**
   * A：現流海鮮是小商人每天深夜親自去崁仔頂魚市場挑選的當季野生好貨，數量非常有限！我們固定於**每日中午 12:00 準時解鎖開賣**（管理員會提前上架供大家預告瀏覽）。因為是限量供應，手腳太慢就會被隔壁鄰居搶光光唷！當畫面顯示「已售完」時，代表當日額度已滿，建議您明天請早或選購常態冷凍區的極鮮商品。
3. **Q3：現流海鮮的價格和重量是怎麼計算的？**
   * A：天然野生現流海鮮無法完全長得一模一樣！我們是以「重量範圍內固定價格」販售（例如 200公克 ±10% 為一個價格單位）。因天然漁獲有自然重量落差，若實際重量有些微溢收，小商人會隨箱「多退少補」，請您絕對放心！
4. **Q4：我可以同時買現流海鮮和常態冷凍商品嗎？運費怎麼計算？**
   * A：完全可以！您可以自由混搭現流搶購區與常態冷凍嚴選區的商品到同一個購物車一次結帳。運費計算規則如下：
     * **合併小計滿 \$3,000 元**：直接幫您 **免運費 (\$0)**！
     * **合併小計滿 \$2,000 ～ $2,999 元**：優惠低溫運費 **\$60 元**。
     * **合併小計未滿 \$2,000 元**：基本低溫運費 **\$130 元**。
5. **Q5：下單後要去哪裡匯款？為什麼在網頁上找不到完整的銀行帳號？**
   * A：為了防止網路詐騙與保護個資，**本站的網頁公開區域絕對不會顯示任何完整的銀行帳號**。當您完成下單後，系統會彈出成功視窗，並同步**自動發送「訂單成立通知信」到您的 Google 信箱**，信件中就會完整提供中國信託（822）的匯款帳號（`200532784005`）。
6. **Q6：匯款後該怎麼回報？要填哪些資料？**
   * A：請您將款項匯至指定帳號後，直接複製我們確認信中的回信格式，回覆您的匯款金額、帳號後 5 碼、收件人姓名、手機，以及為了避免超商拒收特別規範的「7-11 門市名稱」與「全家門市名稱」各一。小商人確認入帳後，會手動幫您點擊後台核銷，並寄發「核銷成功通知信」。
7. **Q7：出貨週期是怎麼計算的？如果買多筆訂單可以合併嗎？**
   * A：本站的出貨週期為「每週二中午 12:00 起算至當週週日中午 12:00 為一個完整出貨週期」。系統會自動將同一位買家（透過 Google UID 識別）在當週內的所有訂單進行智慧併單，結算總金額與運費，並在該週期結束後統一安排低溫出貨。

   * A：

    * A：崁仔頂的海鮮講求的就是一個「青」！現流及冷凍海鮮請盡速放入冷凍庫或冷藏保存。每筆訂單頁面與信件都有貼心提醒，建議在每週出貨週期內烹調享用，才能吃到最鮮甜的海味喔！若有任何烹飪或解凍上的疑問，隨時歡迎在私人留言區敲小商人！
