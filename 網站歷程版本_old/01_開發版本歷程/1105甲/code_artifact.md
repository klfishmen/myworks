# ⚓ 基隆鮮物．崁仔頂小商人 (khàm-tíng) 系統最終規格與操作手冊 (2026 旗艦完整版)

本文件為「基隆鮮物．崁仔頂小商人」電商、自動化對帳與雲端後台管理系統之最終完整操作手冊。本系統完美結合了**圖文並茂的商品管理後台**、**防重複點擊的買家前台**以及 **Google 試算表作為中央資料庫**的黃金三元架構。

---

## 一、 核心三者關係與運作架構 (Frontend ⇄ Backend ⇄ Google Sheets)

本系統採用「前後端分離與雲端資料庫」的現代化架構，三者扮演著相輔相成的角色：

1. **買家前台 (`index.html`)**：
   * 買家的主戰場。提供每日現流漁獲專區、常態冷凍嚴選（16樣）、詳細商品說明欄、圖片展示、雙軌留言板（公開討論區與私人私訊）及購物車結帳。
   * 具備**防重複點擊鎖定機制**（點擊送出訂單後按鈕立即轉為 `disabled` 與 Loading 狀態），徹底防止心急重複下單。
2. **後台管理者控制台 (`main.html`)**：
   * 小商人的主戰場。支援現流與冷凍商品的**完整圖檔網址、規格、價格、庫存與說明欄即時維護**，並提供訂單明細展開、手動確認收款與防重複出貨標記。
3. **Google 試算表與後端 API (`code.js` / Google Apps Script)**：
   * 系統的**中央大腦與最終真理（Single Source of Truth）**。
   * 當買家下單時，資料自動寫入 Google 試算表（同步更新「訂單記錄」、「客戶資料庫」、「對話備份」）；當後台點擊「重新載入雲端訂單」時，系統即時從試算表抓取最新進度。

## 二、 部署指南與操作步驟

### 1. Google Apps Script 後端部署步驟 (`code.js`)
1. 開啟您的 Google 試算表（ID: `1pkd-D_OL_tER0X4CAEcvGACt3hJezqr3_PEXyxwy_Cc`）。
2. 點擊上方選單 **「擴充功能」 ➔ 「Apps Script」**。
3. 將最新的純後端 JavaScript 程式碼貼入 `程式碼.gs` 中並點擊**儲存（磁片圖示）**。
4. 點擊右上角 **「部署」 ➔ 「管理部署」**。
5. 點擊現有部署旁的**編輯（鉛筆圖示）**，將版本下拉選單切換為 **「新版本 (New version)」**，然後點擊 **「部署 (Deploy)」**。
   * *注意：此操作會保持您的部署執行網址（`.../exec`）完全不變，但後端程式碼已升級至最新版。*

### 2. 前台與後台網頁部署
* 將 `index.html` 與 `main.html` 部署至您的靜態主機（如 GitHub Pages、Netlify 或 Vercel）。
* 確保前端程式碼中的 `API_URL` 變數已正確填入您的 Google Apps Script 部署執行網址。

## 三、 六大核心功能模組說明

1. **現流與冷凍獨立管理**：
   * 現流商品強調每日新鮮直配與庫存即時扣減（售完自動鎖定）；冷凍嚴選提供常態供應與豐富的規格說明。
2. **商品圖檔與詳細欄位維護**：
   * 後台支援圖片網址（Image URL）、品名、規格、說明、價格與庫存的即時新增與編輯。
3. **訂單記錄與出貨明細展開**：
   * 後台可一目了然檢視買家購買品項明細、匯款後 5 碼、7-11 與全家雙超商門市備用資料，確保物流暢通。
4. **防重複點擊與防呆機制**：
   * 買家結帳送出訂單時按鈕自動鎖定，杜絕重複下單；後台具備「印畢標記已出貨」防止重複出貨。
5. **雙軌留言板與對話備份**：
   * 公開討論區供 LINE 群組式交流，私人私訊會自動同步備份至 Google 試算表的「對話備份」分頁。
6. **VIP 客戶資料庫自動累積**：
   * 系統自動統計每位買家的累計消費金額、消費次數與雙超商門市偏好。
