# ⚓ 基隆鮮物．崁仔頂小商人 (khàm-tíng) 系統規格與操作手冊 (2026 旗艦版)

本文件為「基隆鮮物．崁仔頂小商人」電商、一鍵對帳與後台管理系統之完整規格說明。包含最新升級的 **Email 直連對帳回報按鈕、雙超商門市選單（防冷凍庫滿載退單）、24 小時限時庫存保留機制，以及手動審核出貨與防重複列印機制**。

---

## 一、 核心功能與升級亮點

1. **Email 直連一鍵對帳 (One-Click Remittance Report)**
   - 買家下單後，後端 Google Apps Script 會發送帶有高亮巨型按鈕的 HTML 信件：**「👉 按此一鍵填寫匯款與門市資料 (免複製)」**。
   - 買家點擊後直接跳轉至 `index.html` 對帳專用彈窗，自動帶入 `orderId`，免複製貼上即可秒速填單。

2. **雙超商門市地圖與出貨選項 A/B/C (Double Convenience Store Backup)**
   - **7-11 + 全家雙門市填寫**：提供 7-11 與全家電子地圖一鍵查詢按鈕，避免因單一門市冷凍庫滿載而被退單。
   - **A/B/C 出貨偏好**：可選擇「週二~週四第一批出貨」、「週五~週日週末出貨」或「配合現流齊全再出貨」。

3. **24 小時限時庫存保留 (24hr Reserve Logic)**
   - 前台下單時提供「現流漁獲限時保留 24 小時」警示，避免買家下單後未匯款造成囤單。

4. **手動確認收款與防重複出貨機制 (Settlement & Anti-Duplicate Print)**
   - **手動審核**：管理者於後台對帳無誤後，需手動點擊 **「✓ 確認已收款」**，該筆訂單才會放行傳送至 **「待出貨明細單」**。
   - **防重複出貨**：列印出貨單後點擊 **「印畢標記已出貨」**，系統將自動隱藏該單並永久備份至歷史紀錄庫。

## 二、 檔案架構說明

本系統由三個極簡、完全獨立且互相連動的檔案組成：

| 檔案名稱 | 說明 |
| :--- | :--- |
| `google_apps_script.js` | 後端腳本：處理 POST 請求（新建訂單/更新對帳），寄送帶有直連對帳按鈕的 HTML 郵件。 |
| `index.html` | 前台官方購物頁與顧客一鍵對帳彈窗（包含 24 小時保留提示、7-11與全家地圖查詢）。 |
| `main.html` | 後台管理者控制台：包含手動確認收款、待出貨單列印、歷史檔案庫與庫存管理。 |

## 三、 系統部署與營運操作指南

### 步驟一：建立 Google 試算表資料庫
1. 請前往 [Google 試算表](https://sheets.google.com) 建立一個新試算表，命名為 **`1105崁仔頂後台`**。
2. 確保試算表具備分頁 **`訂單紀錄`**。系統首次執行時將自動建立包含以下 15 個欄位的表頭：
   > `訂單編號` \| `下單時間` \| `買家Email` \| `手機後4碼` \| `應付總額` \| `匯款金額` \| `匯款後5碼` \| `收件人姓名` \| `收件人手機` \| `7-11門市` \| `全家門市` \| `出貨選項` \| `結單狀態` \| `出貨狀態` \| `商品明細`

### 步驟二：部署 Google Apps Script 後端
1. 進入試算表選單：**「擴充功能」 ➔ 「Apps Script」**。
2. 清空原本內容，貼上最新的 `google_apps_script.js` 程式碼。
3. 修改程式碼中的對帳網址（`reportUrl`），將其設定為您前台 `index.html` 的實際部署網址：
   ```javascript
   var reportUrl = "https://your-domain.com/index.html?orderId=" + encodeURIComponent(data.orderId);
   ```
4. 點擊右上角 **「部署」 ➔ 「新增部署作業」**：
   - **類型**：網頁應用程式 (Web App)
   - **執行身分**：我 (Me)
   - **誰可以存取**：任何人 (Anyone)
5. 點擊部署並完成帳戶授權，複製取得的 **Web App URL**（結尾為 `/exec`）。

### 步驟三：更新前端 API 網址並上線
1. 將取得的 `/exec` 網址填入 `index.html` 內的 `this.googleSheetsApiUrl` 變數中。
2. 使用 VS Code Live Server、GitHub Pages 或任何 Web 主機即可立即正式營運！

## 四、 營運標準作業流程 (SOP)

```
[買家前台下單] 
     │
     ▼ (自動寄送 Email + 一鍵回報按鈕)
[買家點擊信件按鈕] ➔ [跳轉 index.html 對帳彈窗] ➔ [填寫帳號後5碼 + 雙門市地圖 + 出貨選項]
     │
     ▼ (資料寫入 Google 試算表 & 發送通知)
[管理者開啟 main.html 後台]
     │
     ├── 1. 於「訂單審核與對帳結單」點擊【✓ 確認已收款】
     │
     ├── 2. 訂單自動移至「📦 待出貨明細單」
     │
     ├── 3. 按下【🖨️ 列印目前出貨單】進行出貨包裝
     │
     └── 4. 點擊【印畢標記已出貨】➔ 自動封存至「📜 歷史已出貨紀錄」（防重複出貨）
```
