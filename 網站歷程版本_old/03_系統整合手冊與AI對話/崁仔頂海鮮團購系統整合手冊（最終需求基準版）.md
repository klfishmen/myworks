# 崁仔頂海鮮團購系統整合手冊（最終需求基準版）

**文件用途：** 系統建置、日常營運、結算對帳、出貨及新人訓練  
**依據：** 1020 Gemini 最終需求基準（整合常態冷凍表單、現流每月獨立分頁、雙軌合併、防重複寄信、價格解析與出貨對帳核對）  
**重要原則：** 本文件整理的是建議採用的統一流程。正式上線前，須確認 Google 試算表分頁、表單欄位與 Apps Script 程式版本一致。

---

## 1. 系統目的與核心架構

本系統以一份中央 Google 試算表作為主要資料來源，將兩種訂單管道與付款、配送資料整合，產生每位顧客的合併訂單、應付金額及出貨資料。

### 1.1 雙軌訂單

| 訂單類型 | 顧客下單方式 | 內部資料來源 | 自動化／人工工作 |
| :--- | :--- | :--- | :--- |
| **常規冷凍商品** | Google 表單 A | `常態表單` | 表單回覆自動寫入；依商品標題價格欄位計算金額，並自動寄出初步確認 Email（CC 管理員） |
| **現流海鮮** | LINE 群組／記事本留言 `+1` | 當月現流分頁（例如 `11月現流`） | 管理員結單後手動登打顧客資料、商品及數量；從 E 欄起向右新增商品欄 |
| **匯款與收件資料** | Google 表單 C | `對帳回報` | 自動記錄付款回報與配送資料，結算時供樞紐表比對 |
| **私訊、改單、客訴** | LINE／Messenger | `訊息追蹤` | 人工記錄、追蹤並於出貨前確認處理完畢 |

### 1.2 核心工作順序

1. 常規冷凍商品透過表單進單，系統自動解析欄位標題中的價格、計算品項、數量與金額，並寄送初步確認 Email。
2. 現流商品由管理員依 LINE `+1` 喊單紀錄，手動登打至當月現流分頁（每日新增商品向右延伸）。
3. 更新樞紐總表，優先以 Email 識別顧客，無 Email 時以「暱稱＋手機後四碼」比對，將同一位顧客的冷凍與現流訂單合併。
4. 依合併後商品小計計算一次運費及應付總額。
5. 將對帳回報中的匯款後五碼、收件人與配送資訊帶入／比對。
6. 人工核對訂單、金額、收款與配送資料（實際入帳仍需人工確認）。
7. 產生出貨對帳表，確認未處理訊息與例外狀況後安排出貨。

> **版本注意：** 系統設計將「更新樞紐」與「寄送未寄送確認信」分開操作，並內建防重複寄送機制，避免重複執行時再次發信。

## 2. 每日與每週實際營運時程

### 2.1 現流上架時程

| 時間／日期 | 工作內容 |
| :--- | :--- |
| **每日凌晨 05:00 左右** | 預告當日可能上架的現流海鮮；預告不代表一定開團 |
| **每日中午 12:00** | 確定開團的商品上架至 LINE 群組記事本 |
| **商品上架後** | 顧客在對應商品下方留言 `+1`，依公告規則喊單 |
| **確認有買到當日** | 顧客須於當日 23:30 前完成匯款及收件資料填寫 |
| **每週二至週六** | 原則上會有新品上架；週日視貨況安排 |
| **週六至週日** | 管理員整理並公布本週對帳記事本，最晚週日公布 |
| **隔週週二至週三** | 確認匯款與收件資料無誤後，原則上安排出貨 |

海鮮以品質與實際貨況優先，沒有合適商品時不勉強開團。實際上架、收單及出貨安排仍以當次公告為準。

### 2.2 每日管理員工作

* **開工前：** 查看 LINE 群組、記事本及 Messenger 私訊；確認當日預告、商品售價、數量及公告內容；查看 `訊息追蹤` 中尚未處理的項目。
* **接單期間：** 確認常規冷凍表單是否正常回覆；依現流 `+1` 喊單記錄處理顧客問題；私訊詢問、改單、取消、特殊需求或客訴記錄到 `訊息追蹤`。
* **當日結束前：** 提醒現流已買到顧客在 23:30 前匯款並填寫收件資料；檢查當日新訂單是否有缺資料、重複登打或待確認事項。

### 2.3 每週工作流程

1. **發布商品：** 預告並上架現流商品，清楚標示品名、售價、數量及喊單規則。
2. **接單：** 常規冷凍訂單由 Google 表單進單；現流訂單由 LINE `+1` 形成。
3. **現流結單：** 管理員將 `+1` 訂單登打至正確月份的現流分頁，並每日向右新增商品欄。
4. **結算前檢查：** 檢查品名、售價、數量、顧客識別資料及 Email。
5. **更新樞紐：** 合併同一顧客的常規冷凍與現流訂單，計算商品小計、合併小計、運費與應付總額。
6. **寄送合併確認信：** 檢查樞紐結果後，執行寄送未寄送確認信（具防重寄保護）。
7. **收款與回報：** 顧客依通知匯款並填寫對帳／收件表單。
8. **產生出貨對帳表：** 比對應付金額、匯款後五碼、收件人、電話及配送資料。
9. **人工覆核：** 確認收款已核實、資料完整、未處理訊息已解決。
10. **安排出貨：** 依每週公告及既定出貨節奏安排，原則上為隔週週二至週三。

## 3. Google 表單與回覆試算表

系統設計包含兩張 Google 表單，以及其回覆／中央資料表的分頁。

### 3.1 Google 表單 A：常規冷凍商品訂購表單
* **用途：** 顧客訂購常規冷凍商品。
* **關鍵欄位：** 時間戳記、Email、LINE 群組暱稱、手機後四碼、各常規商品訂購欄位（商品標題需包含清楚品名與售價，例如 `挪威鮭魚 $350`、`挪威鮭魚 NT$350`、`挪威鮭魚 350元`）。
* **流程：** 顧客填寫送出 $\rightarrow$ 自動寫入 `常態表單` $\rightarrow$ 自動解析標題價格、計算金額並寄送初步確認 Email（CC 管理員） $\rightarrow$ 結算時再與現流訂單合併重新計算每週運費。

### 3.2 Google 表單 C：匯款與配送回報表單
* **用途：** 顧客回報匯款資訊與收件／配送資料。
* **關鍵欄位：** 時間戳記、Email、買家暱稱、手機後四碼、匯款帳號後五碼、收件人姓名、收件電話、收件地址／配送方式。

### 3.3 回覆試算表與中央分頁關係
* `常態表單`：Google 表單 A 回覆。
* `對帳回報`：Google 表單 C 回覆。
* 比如 `11月現流` 等月份分頁：管理員手動登打現流訂單。
* `樞紐總表`：系統整合訂單與結算金額的主要結果。
* `出貨對帳表`：人工核對收款與出貨資訊。

| 列／欄 | A 欄 | B 欄 | C 欄 | D 欄 | E 欄起（每日新增商品） |
| :--- | :--- | :--- | :--- | :--- | :--- |

| **第 3 列** | 電子信箱 | 社群暱稱 | 手機後四碼 | 臉書帳號 | **各商品名稱**（跨週商品可加日期前綴） |
| **第 4 列起** | 顧客 Email | 顧客暱稱 | 手機後四碼 | FB 帳號 | **各顧客對應商品的購買數量** |

**每日新增商品操作方式：**
1. 找到當月現流分頁（例如 `11月現流`）。
2. 在最右側空白欄（如 E 欄之後）新增商品欄。

4. 第 3 列填入商品名稱。
5. 在每位顧客對應的列中填入購買數量。
6. 更新樞紐時，程式會自動從 E 欄開始讀取售價、品名與數量。

## 5. 雙軌合併、運費與應付總額計算

### 5.1 雙軌合併機制
* **優先識別：** 優先以 `Email` 比對同一位顧客。
* **次要識別：** 當無 Email 時，使用 `「暱稱＋手機後四碼」` 進行比對與合併。
* **無 Email 處理：** 訂單照常合併、計算金額與出貨資料，但系統會將其列入無 Email 名單，不自動寄送 Email，改由管理員人工通知。

### 5.2 運費計算規則
運費以 **常規冷凍商品小計 ＋ 現流商品小計的合併總小計** 計算（冷凍初步信件與每週合併結算信分開，合併時重新依總小計計費）：

| 合併商品總小計 | 運費金額 | 說明 |
| :--- | :--- | :--- |
| **$\ge$ NT\$3,000** | NT\$0 | 免運費 |
| **$\ge$ NT\$2,000 且 $<$ NT\$3,000** | NT\$60 | 滿 2,000 元優惠運費 |
| **$<$ NT\$2,000** | NT\$130 | 未滿 2,000 元運費 |

## 6. 結算與出貨 SOP（管理員版）

1. **檢查常態表單：** 確認 Google 表單 A 回覆已進入 `常態表單`，自動確認信正常發送。
2. **登打現流訂單：** 對照 LINE 記事本喊單，至當月現流分頁（如 `11月現流`）手動維護客戶資料，並在最右側新增每日商品欄位（填妥第 2 列售價與第 3 列品名）。
3. **結算前檢查：** 透過選單執行「更新樞紐總表（不寄信）」，系統會自動檢查售價解析與無 Email 顧客名單。
4. **寄送合併確認信：** 確認樞紐無誤後，執行「寄送未寄送訂單確認信」（系統會自動標記已寄送，避免重複寄信）。
5. **付款與對帳核實：** 查看 `對帳回報`，並**人工核對實際銀行入帳**（注意：顧客填表不代表銀行已入帳）。
6. **產生出貨對帳表：** 執行「產生出貨對帳表」，逐筆核對商品、總額、收款狀態與配送資料。
7. **安排出貨：** 確認款項與資料無誤後，依排程（原則上隔週週二至週三）安排出貨。

## 7. Google Apps Script 完整程式碼

以下為符合上述所有核心需求的完整 Apps Script 原始碼（包含選單、防重複寄信、每日現流向右讀取、價格解析與雙軌合併）。請直接複製並貼至 Google 試算表的 Apps Script 編輯器中。

```javascript
/**
 * 崁仔頂海鮮團購 - 雙軌自動化管理系統（最終需求基準版本）
 * 核心功能：
 * 1. 常態冷凍表單自動回信（解析標題價格、運費計算、CC 管理員）
 * 2. 現流每月獨立分頁，支援從 E 欄起向右每日新增商品欄（第 2 列售價、第 3 列品名）
 * 3. 雙軌合併：優先 Email 識別，無 Email 時用「暱稱＋手機後四碼」比對
 * 4. 更新樞紐與寄信分離，內建防重複寄信機制
 * 5. 產生出貨對帳表與建立新月份現流分頁
 */

const CONFIG = {
  SHEET_REGULAR: '常態表單',
  SHEET_PAYMENT: '對帳回報',
  SHEET_HUB: '樞紐總表',
  SHEET_SHIPPING: '出貨對帳表',
  SHEET_SETTING: '系統設定',
  SHEET_MSG: '訊息追蹤',

  BANK_NAME: '中國信託',
  BANK_CODE: '822',
  BANK_ACCOUNT: '200532784005',
  OWNER_EMAIL: 'twvisa2009@gmail.com',

  SHIPPING: {
    freeThreshold: 3000,
    midThreshold: 2000,
    feeFree: 0,
    feeMid: 60,
    feeLow: 130
  }
};

function onOpen() {
  SpreadsheetApp.getUi()
    .createMenu('崁仔頂中央大腦')
    .addItem('1. 更新樞紐總表（不寄信）', 'updateCentralBrainOnly')
    .addItem('2. 寄送未寄送訂單確認信', 'sendPendingOrderEmails')
    .addItem('3. 產生出貨對帳表', 'generateShippingList')
    .addItem('4. 建立新月份現流分頁', 'createNewMonthFreshSheet')
    .addToUi();
}

function initSheets() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();

  const settingSheet = getOrCreateSheet_(ss, CONFIG.SHEET_SETTING);
  if (settingSheet.getLastRow() === 0) {
    settingSheet.getRange(1, 1, 10, 2).setValues([
      ['參數名稱', '數值'],
      ['運費門檻1', 3000],
      ['運費金額1', 0],
      ['運費門檻2', 2000],
      ['運費金額2', 60],
      ['運費金額3', 130],
      ['銀行名稱', CONFIG.BANK_NAME],
      ['銀行代碼', CONFIG.BANK_CODE],
      ['銀行帳號', CONFIG.BANK_ACCOUNT],
      ['管理者信箱', CONFIG.OWNER_EMAIL]
    ]);
    settingSheet.setFrozenRows(1);
  }

  const msgSheet = getOrCreateSheet_(ss, CONFIG.SHEET_MSG);
  if (msgSheet.getLastRow() === 0) {
    msgSheet.appendRow([
      '日期', '管道', '客人暱稱', '手機後四碼',
      '詢問內容', '狀態', '處理結果', '備註'
    ]);
    msgSheet.setFrozenRows(1);
  }

  SpreadsheetApp.getUi().alert('基礎分頁初始化完成。');
}

function getOrCreateSheet_(ss, name) {
  let sheet = ss.getSheetByName(name);
  if (!sheet) sheet = ss.insertSheet(name);
  return sheet;
}

function normalizeEmail_(value) {
  return String(value || '').trim().toLowerCase();
}

function normalizeNickname_(value) {
  return String(value || '')
    .trim()
    .replace(/\s+/g, '')
    .toLowerCase();
}

function normalizePhone4_(value) {
  const digits = String(value || '').replace(/\D/g, '');
  return digits.length === 4 ? digits : '';
}

function findHeaderIndex_(headers, candidates) {
  for (let i = 0; i < headers.length; i++) {
    const header = String(headers[i] || '').trim().toLowerCase();
    for (let j = 0; j < candidates.length; j++) {
      if (header.indexOf(String(candidates[j]).toLowerCase()) !== -1) {
        return i;
      }
    }
  }
  return -1;
}

function parsePrice_(value) {
  const str = String(value || '')
    .replace(/,/g, '')
    .trim();

  let match = str.match(/(?:NT\$|\$|NTD)\s*(\d+(?:\.\d+)?)/i);
  if (match) return Number(match[1]);

  match = str.match(/(\d+(?:\.\d+)?)\s*元/);
  if (match) return Number(match[1]);

  if (/^\d+(?:\.\d+)?$/.test(str)) return Number(str);

  return NaN;
}

function calculateShipping_(subtotal) {
  const s = CONFIG.SHIPPING;

  if (subtotal >= s.freeThreshold) {
    return {
      fee: s.feeFree,
      desc: '免運費（已達 ' + s.freeThreshold + ' 元門檻）'
    };
  }

  if (subtotal >= s.midThreshold) {
    return {
      fee: s.feeMid,
      desc: s.feeMid + ' 元（滿 ' + s.midThreshold + ' 元優惠）'
    };
  }

  return {
    fee: s.feeLow,
    desc: s.feeLow + ' 元（未滿 ' + s.midThreshold + ' 元）'
  };
}

function onFormSubmit(e) {
  if (!e || !e.range) return;

  const sheet = e.range.getSheet();
  if (sheet.getName() !== CONFIG.SHEET_REGULAR) return;

  const headers = sheet
    .getRange(1, 1, 1, sheet.getLastColumn())
    .getValues()[0];

  const row = e.values;

  const emailIdx = findHeaderIndex_(headers, ['電子郵件', 'Email']);
  const nickIdx = findHeaderIndex_(headers, ['line群組的暱稱', '暱稱', '姓名']);

  if (emailIdx === -1 || nickIdx === -1) return;

  const email = normalizeEmail_(row[emailIdx]);
  const nickname = String(row[nickIdx] || '').trim();

  if (!email || email.indexOf('@') === -1 || !nickname) return;

  let subtotal = 0;
  const details = [];

  for (let c = 4; c < headers.length; c++) {
    const itemName = String(headers[c] || '').trim();
    const qty = Number(row[c]) || 0;

    if (!itemName || qty <= 0) continue;

    const price = parsePrice_(itemName);
    if (isNaN(price) || price <= 0) continue;

    const itemTotal = qty * price;
    subtotal += itemTotal;

    details.push(
      '• ' + itemName + ' × ' + qty + ' ＝ ' +
      itemTotal.toLocaleString('zh-TW') + ' 元'
    );
  }

  if (subtotal <= 0) return;

  const shipping = calculateShipping_(subtotal);
  const grandTotal = subtotal + shipping.fee;

  const message = buildOrderEmail_({
    nickname: nickname,
    regularDetails: details,
    freshDetails: [],
    regularSub: subtotal,
    freshSub: 0,
    totalSub: subtotal,
    shipping: shipping,
    grandTotal: grandTotal
  });

  try {
    MailApp.sendEmail(email, '【崁仔頂海鮮團購】常態冷凍訂單確認通知', message, {
      cc: CONFIG.OWNER_EMAIL
    });
  } catch (err) {
    console.error('常態表單自動寄信失敗：' + err.message);
  }
}

function updateCentralBrainOnly() {
  const ui = SpreadsheetApp.getUi();
  const ss = SpreadsheetApp.getActiveSpreadsheet();

  const lock = LockService.getScriptLock();
  if (!lock.tryLock(30000)) {
    ui.alert('目前有另一個結算作業執行中，請稍後再試。');
    return;
  }

  try {
    const response = ui.prompt(
      '結算現流分頁',
      '請輸入要結算的現流分頁名稱，例如：11月現流',
      ui.ButtonSet.OK_CANCEL
    );

    if (response.getSelectedButton() !== ui.Button.OK) return;

    const freshSheetName = response.getResponseText().trim();
    if (!freshSheetName) {
      ui.alert('請輸入現流分頁名稱，例如：11月現流');
      return;
    }

    const freshSheet = ss.getSheetByName(freshSheetName);
    if (!freshSheet) {
      ui.alert('找不到分頁：「' + freshSheetName + '」，請確認名稱是否完全一致。');
      return;
    }

    const regularSheet = ss.getSheetByName(CONFIG.SHEET_REGULAR);
    const paymentSheet = ss.getSheetByName(CONFIG.SHEET_PAYMENT);

    const masterMap = {};
    const aliasMap = {};
    const priceErrors = [];
    const noEmailCustomers = [];

    if (regularSheet && regularSheet.getLastRow() > 1) {
      processRegularToMap_(regularSheet, masterMap, aliasMap, priceErrors);
    }

    if (freshSheet.getLastRow() > 3) {
      processFreshToMap_(freshSheet, masterMap, aliasMap, priceErrors);
    }

    if (paymentSheet && paymentSheet.getLastRow() > 1) {
      processPaymentToMap_(paymentSheet, masterMap, aliasMap);
    }

    writeHubSheet_(ss, masterMap, noEmailCustomers);

    let alertMessage = '樞紐總表已更新完成。\n\n';
    alertMessage += '本次未寄送任何 Email。\n';
    alertMessage += '請確認資料後，再執行「寄送未寄送訂單確認信」。\n';

    if (noEmailCustomers.length > 0) {
      alertMessage += '\n以下顧客有訂單但無 Email，請人工聯繫或補填：\n';
      alertMessage += noEmailCustomers.join('\n');
    }

    if (priceErrors.length > 0) {
      alertMessage += '\n\n以下商品售價無法解析，請檢查：\n';
      alertMessage += priceErrors.join('\n');
    }

    ui.alert(alertMessage);
  } finally {
    lock.releaseLock();
  }
}

function processRegularToMap_(sheet, masterMap, aliasMap, priceErrors) {
  const data = sheet.getDataRange().getValues();
  if (data.length < 2) return;

  const headers = data[0];
  const emailIdx = findHeaderIndex_(headers, ['電子郵件', 'Email']);
  const nickIdx = findHeaderIndex_(headers, ['line群組的暱稱', '暱稱', '姓名']);
  const phoneIdx = findHeaderIndex_(headers, ['手機後四碼', '電話末四碼']);

  if (nickIdx === -1) return;

  for (let i = 1; i < data.length; i++) {
    const row = data[i];
    const email = emailIdx !== -1 ? normalizeEmail_(row[emailIdx]) : '';
    const nickname = String(row[nickIdx] || '').trim();
    const phone4 = phoneIdx !== -1 ? normalizePhone4_(row[phoneIdx]) : '';

    if (!nickname) continue;

    const key = resolveIdentityKey_(email, nickname, phone4, aliasMap);
    if (!masterMap[key]) {
      masterMap[key] = createOrderObject_(email, nickname, phone4);
    }

    if (email) {
      masterMap[key].email = email;
      if (phone4) {
        aliasMap['N:' + normalizeNickname_(nickname) + '_' + phone4] = key;
      }
    }
    if (phone4 && !masterMap[key].phone4) {
      masterMap[key].phone4 = phone4;
    }

    let subtotal = 0;
    const details = [];

    for (let c = 4; c < headers.length; c++) {
      const itemName = String(headers[c] || '').trim();
      const qty = Number(row[c]) || 0;

      if (!itemName || qty <= 0) continue;

      const price = parsePrice_(itemName);
      if (isNaN(price) || price <= 0) {
        priceErrors.push('常態表單：' + itemName);
        continue;
      }

      const itemTotal = qty * price;
      subtotal += itemTotal;
      details.push('• ' + itemName + ' × ' + qty + ' ＝ ' + itemTotal.toLocaleString('zh-TW') + ' 元');
    }

    if (subtotal > 0) {
      masterMap[key].regularSub += subtotal;
      masterMap[key].regularDetails = masterMap[key].regularDetails.concat(details);
    }
  }
}

function processFreshToMap_(sheet, masterMap, aliasMap, priceErrors) {
  const data = sheet.getDataRange().getValues();
  if (data.length < 4) return;

  const prices = data[1];
  const itemNames = data[2];

  for (let i = 3; i < data.length; i++) {
    const row = data[i];
    const email = normalizeEmail_(row[0]);
    const nickname = String(row[1] || '').trim();
    const phone4 = normalizePhone4_(row[2]);

    if (!nickname) continue;

    const key = resolveIdentityKey_(email, nickname, phone4, aliasMap);
    if (!masterMap[key]) {
      masterMap[key] = createOrderObject_(email, nickname, phone4);
    }

    if (email) {
      masterMap[key].email = email;
      if (phone4) {
        aliasMap['N:' + normalizeNickname_(nickname) + '_' + phone4] = key;
      }
    }
    if (phone4 && !masterMap[key].phone4) {
      masterMap[key].phone4 = phone4;
    }

    let subtotal = 0;
    const details = [];

    for (let c = 4; c < itemNames.length; c++) {
      const itemName = String(itemNames[c] || '').trim();
      const qty = Number(row[c]) || 0;

      if (!itemName || qty <= 0) continue;

      if (/範例|測試|請刪除/.test(itemName)) {
        priceErrors.push('現流分頁範本資料：「' + itemName + '」，請先刪除。');
        continue;
      }

      const price = parsePrice_(prices[c]);
      if (isNaN(price) || price <= 0) {
        priceErrors.push('現流分頁「' + sheet.getName() + '」商品：「' + itemName + '」，售價格式有誤');
        continue;
      }

      const itemTotal = qty * price;
      subtotal += itemTotal;
      details.push('• ' + itemName + ' × ' + qty + ' ＝ ' + itemTotal.toLocaleString('zh-TW') + ' 元');
    }

    if (subtotal > 0) {
      masterMap[key].freshSub += subtotal;
      masterMap[key].freshDetails = masterMap[key].freshDetails.concat(details);
    }
  }
}

function processPaymentToMap_(sheet, masterMap, aliasMap) {
  const data = sheet.getDataRange().getValues();
  if (data.length < 2) return;

  const headers = data[0];
  const emailIdx = findHeaderIndex_(headers, ['電子郵件', 'Email']);
  const nickIdx = findHeaderIndex_(headers, ['買家暱稱', '暱稱']);
  const phoneIdx = findHeaderIndex_(headers, ['手機後四碼', '電話末四碼']);
  const payIdx = findHeaderIndex_(headers, ['匯款帳號後五碼']);
  const shipIdx = findHeaderIndex_(headers, ['收件', '配送']);

  for (let i = 1; i < data.length; i++) {
    const row = data[i];
    const email = emailIdx !== -1 ? normalizeEmail_(row[emailIdx]) : '';
    const nickname = nickIdx !== -1 ? String(row[nickIdx] || '').trim() : '';
    const phone4 = phoneIdx !== -1 ? normalizePhone4_(row[phoneIdx]) : '';
    const payCode = payIdx !== -1 ? String(row[payIdx] || '').trim() : '';
    const shipInfo = shipIdx !== -1 ? String(row[shipIdx] || '').trim() : '';

    if (!nickname && !email) continue;

    const key = resolveIdentityKey_(email, nickname, phone4, aliasMap);
    if (!masterMap[key]) continue;

    if (payCode) masterMap[key].payCode = payCode;
    if (shipInfo) masterMap[key].shipInfo = shipInfo;
  }
}

function resolveIdentityKey_(email, nickname, phone4, aliasMap) {
  if (email) return 'E:' + email;
  const aliasKey = 'N:' + normalizeNickname_(nickname) + '_' + phone4;
  if (aliasMap[aliasKey]) return aliasMap[aliasKey];
  return aliasKey;
}

function createOrderObject_(email, nickname, phone4) {
  return {
    email: email,
    nickname: nickname,
    phone4: phone4,
    regularSub: 0,
    regularDetails: [],
    freshSub: 0,
    freshDetails: [],
    payCode: '',
    shipInfo: '',
    sent: false
  };
}

function writeHubSheet_(ss, masterMap, noEmailCustomers) {
  const hubSheet = getOrCreateSheet_(ss, CONFIG.SHEET_HUB);
  hubSheet.clear();

  const headers = [
    '電子郵件',
    '手機後四碼',
    '買家暱稱',
    '常態商品小計',
    '現流商品小計',
    '商品總小計',
    '運費',
    '應付總額',
    '匯款後五碼',
    '收件／配送資訊',
    '出貨狀態',
    '寄信狀態',
    '最後寄信時間',
    'Email回信明細'
  ];

  hubSheet.appendRow(headers);
  hubSheet.setFrozenRows(1);

  const output = [];

  for (const key in masterMap) {
    const order = masterMap[key];
    const totalSub = order.regularSub + order.freshSub;

    if (totalSub <= 0) continue;

    const shipping = calculateShipping_(totalSub);
    const grandTotal = totalSub + shipping.fee;

    const emailMessage = buildOrderEmail_({
      nickname: order.nickname,
      regularDetails: order.regularDetails,
      freshDetails: order.freshDetails,
      regularSub: order.regularSub,
      freshSub: order.freshSub,
      totalSub: totalSub,
      shipping: shipping,
      grandTotal: grandTotal
    });

    if (!order.email) {
      noEmailCustomers.push('• ' + order.nickname + (order.phone4 ? '（手機後四碼 ' + order.phone4 + '）' : ''));
    }

    output.push([
      order.email,
      order.phone4,
      order.nickname,
      order.regularSub,
      order.freshSub,
      totalSub,
      shipping.fee,
      grandTotal,
      order.payCode,
      order.shipInfo,
      '未出貨',
      order.sent ? '已寄送' : '未寄送',
      order.sentAt || '',
      emailMessage
    ]);
  }

  if (output.length > 0) {
    hubSheet.getRange(2, 1, output.length, headers.length).setValues(output);
  }
  hubSheet.setColumnWidth(14, 500);
}

function sendPendingOrderEmails() {
  const ui = SpreadsheetApp.getUi();
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const hubSheet = ss.getSheetByName(CONFIG.SHEET_HUB);

  if (!hubSheet || hubSheet.getLastRow() <= 1) {
    ui.alert('請先執行「更新樞紐總表（不寄信）」。');
    return;
  }

  const lock = LockService.getScriptLock();
  if (!lock.tryLock(30000)) {
    ui.alert('目前有另一個寄信作業執行中，請稍後再試。');
    return;
  }

  try {
    const data = hubSheet.getDataRange().getValues();
    const headers = data[0];

    const emailIdx = headers.indexOf('電子郵件');
    const sentIdx = headers.indexOf('寄信狀態');
    const sentAtIdx = headers.indexOf('最後寄信時間');
    const messageIdx = headers.indexOf('Email回信明細');
    const nicknameIdx = headers.indexOf('買家暱稱');

    let sentCount = 0;
    let skippedNoEmail = 0;
    let failedCount = 0;
    const failedList = [];

    for (let i = 1; i < data.length; i++) {
      const row = data[i];
      const email = normalizeEmail_(row[emailIdx]);
      const nickname = String(row[nicknameIdx] || '').trim();
      const message = String(row[messageIdx] || '');

      if (row[sentIdx] === '已寄送') continue;

      if (!email || email.indexOf('@') === -1) {
        skippedNoEmail++;
        continue;
      }

      try {
        MailApp.sendEmail(email, '【崁仔頂海鮮團購】本週合併訂單與對帳通知', message, {
          cc: CONFIG.OWNER_EMAIL
        });

        hubSheet.getRange(i + 1, sentIdx + 1).setValue('已寄送');
        hubSheet.getRange(i + 1, sentAtIdx + 1).setValue(
          Utilities.formatDate(new Date(), Session.getScriptTimeZone(), 'yyyy-MM-dd HH:mm:ss')
        );
        sentCount++;
      } catch (err) {
        failedCount++;
        failedList.push(nickname + '：' + err.message);
      }
    }

    let result = '寄信作業完成。\n\n';
    result += '成功寄出：' + sentCount + ' 封\n';
    result += '略過無 Email：' + skippedNoEmail + ' 筆\n';
    result += '寄信失敗：' + failedCount + ' 筆\n';
    result += '\n所有成功寄出的信件皆已 CC 管理員。';

    if (failedList.length > 0) {
      result += '\n\n失敗名單：\n' + failedList.join('\n');
    }

    ui.alert(result);
  } finally {
    lock.releaseLock();
  }
}

  }

  const shippingSheet = getOrCreateSheet_(ss, CONFIG.SHEET_SHIPPING);

  const headers = [
    '電子郵件', '手機後四碼', '買家暱稱', '常態冷凍小計',
    '手打現流小計', '商品總小計', '運費', '應付總額',

  ];

  shippingSheet.appendRow(headers);
  shippingSheet.setFrozenRows(1);

  const hubData = hubSheet.getDataRange().getValues();
  const output = [];

  for (let i = 1; i < hubData.length; i++) {
    const row = hubData[i];
    const payCode = String(row[8] || '').trim();

      row[0], row[1], row[2], row[3],
      row[4], row[5], row[6], row[7],

    ]);

  if (output.length > 0) {
    shippingSheet.getRange(2, 1, output.length, headers.length).setValues(output);
  }
  shippingSheet.setColumnWidth(10, 300);

  ui.alert('出貨對帳表已產生完成。');
}

function createNewMonthFreshSheet() {

  const ss = SpreadsheetApp.getActiveSpreadsheet();

  const response = ui.prompt(
    '建立新月份現流分頁',
    '請輸入新月份分頁名稱，例如：12月現流',
